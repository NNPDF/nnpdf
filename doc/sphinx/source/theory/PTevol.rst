.. _ptoevolution:


Perturbative PDF evolution
==========================

The evolution of PDFs is fully handled in the `EKO <https://github.com/nnpdf/eko>`_ code,
and the way QCD evolution is calculated is described in great detail `here <https://eko.readthedocs.io/>`_.


Target Mass Corrections
=========================

Target Mass Corrections (TMC) are implemented in `yadism <https://github.com/nnpdf/yadism>`_.
The implementation is described `here <https://yadism.readthedocs.io/en/latest/implementation/TMC.html>`_.
